Derivable Judgement: A Statistical Decision-Making Model

A statistical analysis project focused on applying inferential statistics techniques to evaluate health-related factors affecting disease occurrence. This project demonstrates practical implementation of hypothesis testing, confidence intervals, statistical decision-making, and data analysis using Python.

Project Overview

This project simulates the work of a data analyst in a public health research organization. Using a generated healthcare dataset, statistical methods are applied to identify significant relationships between lifestyle habits, demographic factors, and diseases such as diabetes and hypertension.

The project combines theoretical understanding with practical implementation using Python libraries including NumPy, Pandas, SciPy, StatsModels, Matplotlib, and Seaborn.

Objectives

Apply inferential statistics on healthcare data
Formulate and test statistical hypotheses
Compute confidence intervals and p-values
Perform z-tests, t-tests, chi-square tests, and ANOVA
Analyze covariance and correlation between variables
Interpret statistical outcomes for decision-making
Visualize statistical findings using graphs and heatmaps

Interpretation of Results

The statistical results are interpreted based on significance levels:

If p-value < 0.05
Reject the null hypothesis
Significant relationship exists
If p-value > 0.05
Fail to reject the null hypothesis
No significant relationship detected
